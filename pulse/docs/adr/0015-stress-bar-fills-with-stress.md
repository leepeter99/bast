# The Stress bar fills with stress

This reverses the "full = calm" reading in ADR 0005 and CONTEXT.md. The Stress bar now fills with the stress value itself, 0 to 100, so a fuller bar means more stress. Its brightness runs the other way from ADR 0014: the accent at full brightness when calm, dimmed to 90%, 80% and 65% as stress rises through each quarter, then orange (red on amber) above 75. It still never shines.
