01 / Layout behaviour

Four directions first

Four sample fields use eight preset positions. Each position is checked against both hands with a clearance margin. Each field returns to its preferred top, right, bottom or left position whenever clear. Only blocked fields move to the nearest available safe position. If there is insufficient room, lower-priority fields disappear until space returns.

The thin analog seconds hand ticks in active mode. Data stays stable as it passes; only hour and minute hands trigger relocation. A brief seconds-hand crossing is intentional. Health values are sample data.

Implementation brief / Connect IQ

A small custom layout engine

Use Monkey C: WatchFace handles lifecycle; DataProvider supplies supported values; LayoutEngine tests measured text bounds against hand geometry; Renderer draws data first and hands last. Keep a cached assignment to avoid unnecessary rearrangement.

  1. Compute hour angle = 30 × (hour mod 12) + 0.5 × minute; minute angle = 6 × minute.
  2. Reject data slots intersecting either hand, its outline, the centre pin, or the round display edge.
  3. Restore clear home positions first; relocate blocked fields to the nearest safe slot. Measure actual font bounds on-device. Hide a secondary field when no safe slot exists.
  4. Re-evaluate at minute changes and when waking. Consider clearance for the next minute before committing a placement.
  5. In onEnterSleep, remove all data and use the analog-only renderer. Restore the active layout in onExitSleep.
  6. Verify a full 12-hour cycle, multiple text lengths, missing sensor values, transitions and AOD behaviour before release.

The browser implements conservative rectangle/hand clearance at the selected minute; next-minute prediction is a production enhancement. Garmin provides drawing and power-state hooks; automatic collision avoidance is our own logic. Treat this metric list as a design target, not confirmed FR965 API coverage. In Connect IQ, expose supported fields through settings; provide an unavailable state for missing readings and handle weather freshness and units. Verify recovery time, Body Battery, resting heart rate and weather access on FR965 before promising them in the release. A production second zone needs maintained daylight-saving rules or user-set offsets.
